# Metodologie

Każda metodologia jest przechowywana w katalogu oznaczonym numerem wersji. Przed oceną trzeba wybrać jedną wersję i nie łączyć jej reguł z regułami innej wersji.

- [0.1](0.1/standard.md) — pierwsza pełna wersja metodologii.
- [0.2](0.2/standard.md) — zmiany stosowane razem z zachowaną podstawą 0.1 oraz osobnymi [kotwicami ocen](0.2/kotwice.md).
- [0.3](0.3/README.md) — samodzielna metodologia zawierająca [pełny standard](0.3/standard.md) i [kotwice ocen](0.3/kotwice.md).

Aktualnym oficjalnym punktem odniesienia jest [zamrożone wydanie v0.3.0](https://github.com/rotnicki/probiernik/releases/tag/v0.3.0). Wersje 0.1 i 0.2 pozostają dostępne jako wcześniejsze, zamrożone etapy rozwoju.
