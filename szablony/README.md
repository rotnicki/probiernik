# Szablony

Szablony są przypisane do konkretnych wersji metodologii. Należy używać szablonu z tego samego katalogu wersji co wybrana metodologia.

- [0.1](0.1/) zawiera kartę oceny i wzór raportu.
- [0.2](0.2/) zawiera kartę oceny i wzór raportu dla wersji 0.2.
- [0.3](0.3/) zawiera kartę oceny, wzór raportu oraz wzór porównania dwóch niezależnych ocen.

Wersja 0.3 jest aktualnym domyślnym wyborem. Starsze szablony pozostają dostępne wyłącznie do pracy z odpowiadającymi im wersjami metodologii.
